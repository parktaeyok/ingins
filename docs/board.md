# 게시판

회사소개 옆 펼침 버튼 → 게시판으로 이동합니다. PC와 모바일에서 같은 하위 메뉴를 사용합니다.

- `/board/`: 최신순 목록, 제목 검색, 10개씩 페이지 이동
- `/board/post/?id=게시글UUID`: 공개 상세 조회
- `/board/write/`: 로그인 후 작성
- `/board/write/?id=게시글UUID`: 본인 글 수정
- 삭제는 본인 글에서 확인창을 거쳐 실행합니다. 글은 일반 텍스트로 저장합니다.

## Supabase 설정

기존 회원가입과 같은 프로젝트 `ejwutsrpugxuexdquchu` 및 공개 환경변수를 사용합니다. 추가 비밀 키나 새 서비스는 필요하지 않습니다. 작성자는 등록 프로필이 있는 로그인 회원이어야 합니다.

1. SQL Editor에서 `select to_regclass('public.site_board_posts');`로 확인합니다.
2. NULL이면 `supabase/setup-board.sql` 전체를 최초 1회 실행합니다. 기존 테이블이 있으면 반복 실행하거나 삭제하지 말고 구조를 확인합니다.
3. 환경변수와 회원가입 설정이 완료된 배포에서 목록 → 로그인 → 작성 → 상세 → 수정 → 삭제를 확인합니다.

2026-10-30 로그인된 Supabase SQL Editor에서 `setup-board.sql`을 적용했습니다. RLS가 활성화되어 있고 정책 4개가 생성된 것을 확인했습니다. `supabase/tests/board-rls.sql`의 허용/차단 검증도 통과했으며 테스트 계정과 글은 모두 롤백되어 남아 있지 않습니다. 해당 테스트는 비회원 조회·쓰기 차단, 본인 글 CRUD, 타인 글 수정·삭제 차단과 작성자 위조 차단을 확인합니다. 설치 SQL을 다시 실행할 필요는 없습니다.

## 권한

비회원은 공개 글만 읽고 작성자 UUID는 조회할 수 없습니다. 회원은 작성자 아이디와 글을 읽으며 본인 글만 작성·수정·삭제합니다. UPDATE 권한은 제목과 본문 열에만 주므로 작성자와 시간을 바꾸지 못합니다. DB 트리거는 사용자가 입력한 표시명이 아닌 본인 등록 프로필의 아이디를 사용합니다. RLS와 열 권한이 직접 REST 요청에도 동일하게 적용됩니다. 개인정보·비밀정보를 게시하지 않도록 작성 화면에서 안내합니다.

관리자 회원관리·타인 글 관리, 첨부파일, 댓글은 이번 게시판 범위에 포함하지 않습니다. 회원 탈퇴 시 해당 계정의 글은 함께 삭제됩니다.
